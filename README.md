# Brand Simulation Engine

A Graph-Augmented Bayesian Simulation Engine designed for SME Marketing Intelligence in Emerging Markets (Bangladesh context). This repository contains the architecture formulated for the Infinity AI BuildFest 2026.

## Architecture Highlights

The engine replaces traditional Multi-Touch Attribution (MTA) with a multi-layered predictive system designed to forecast the causal impact of marketing spend across various channels.

### Six-Layer Stack

1. **Data Sources**: Integrates Endogenous (Meta/Google), Exogenous (Firecrawl web data), and Transactional sales logs.
2. **Ingestion & Processing**: ETL pipelines and Celery queues for processing real-time telemetry.
3. **Storage & Knowledge Base**: 
   - **Neo4j**: Powers the knowledge graph and GraphRAG.
   - **Weaviate / Pinecone**: Stores creative and textual asset embeddings.
   - **BigQuery / Snowflake**: Cold-storage Data Lake.
4. **AI & Simulation Engine (FastAPI & Celery)**:
   - **Bayesian MMM**: `PyMC-Marketing` for macroscopic budget forecasting (with Adstock and Hill transformations).
   - **Agent-Based Modelling**: `Mesa` 3.0 simulating micro-funnel journeys.
   - **Markov Chains**: Stochastic touchpoint credit attribution.
   - **Optimization Engine**: NSGA-II Genetic Algorithms via `pymoo`.
   - **SHAP**: Deterministic mathematical explainability of campaign predictions.
5. **LLM Orchestration**: GraphRAG powered by `LlamaIndex` with a hybrid retrieval pipeline. Cloud models (Claude 3.5 Sonnet / Gemini Flash) with offline fallback (Qwen3-8B via Ollama).
6. **Application (Next.js 15)**: Frontend deployed on Vercel utilizing `shadcn/ui`, `Lightweight Charts`, `next-intl` for native Bangla (code-mixed Banglish) NLP support, and Clerk for authentication. Employs aggressive low-bandwidth edge optimizations for 2G/3G networks.

## Getting Started

### Prerequisites
- Docker Compose v2+
- Node.js 20+
- Python 3.11+

### Local Environment Setup

1. **Backend / Database Services**:
   Spin up the local Redis, Neo4j, and Weaviate instances:
   ```powershell
   docker compose up -d
   ```

2. **Python Worker Configuration**:
   Create a virtual environment and install the AI backend dependencies:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
   Start the Celery worker for simulations:
   ```powershell
   celery -A src.worker.main worker --loglevel=info
   ```

3. **Frontend Application**:
   Navigate to the frontend application:
   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

## Localisation (Bangla)
The frontend utilizes `next-intl` to support seamless locale-based sub-path routing (e.g., `/bn/dashboard`) ensuring accessibility for the SME sector across rural Bangladesh.

## Explanation Engine
All strategic marketing insights generated by the LLM are inherently anchored by a SHAP TreeExplainer running against the Bayesian ML models, guaranteeing that financial allocations represent mathematical reality, not generative hallucination.
