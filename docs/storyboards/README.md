# Storyboards

This directory contains the user experience and interface blueprints for the **Prediction-Engine** project.

*   [gui_storyboard.md](gui_storyboard.md) - A high-level description of the UI screens, user flow, component requirements, and Mermaid.js diagrams. Designed for frontend engineers and UI/UX designers to translate backend capabilities into a Next.js/React interface.
*   [paper_storyboard.md](paper_storyboard.md) - A narrative-focused, scene-by-scene storyboard intended for use in paper-prototyping workshops. Use this to align on user journeys before writing code.

*Note: These are Markdown-based storyboards. They define the "What" and "Why" of the interface flow, rather than providing exact pixel-perfect graphical assets, keeping them easy to update as the engine's APIs evolve.*
